# Stripe Checkout Implementation For A Checkout Fee 
First, I will need to create a table in the Supabase to store the checkout fee details, such as amount, time, status, etc.
Then, I will create a new Stripe checkout session using stripe's sdk , The user will click the "pay application fee" button to initiate the payment 
the frontend will send a **POST** request with **application_id** to the backend endpoint Which creates a "stripe checkout session", it will include the amount to be charged as application fee, this checkout session will output ***session id and session url***. after receiving session id and URL from stripe and it's status(pending/done/cancelled) it will be stored in database(**That is why me made a table earlier**),  next the user will be redirected to the stripe checkout page using the session url provided by stripe.(frontend redirection). once the payment is completed, user will not directly be redirected to the success page, instead, stripe will send a webhook to our backend endpoint notifying about the payment status(checking if the payment is done or failed and if yes than the backend will check the legitimacy of the payment by verifying the webhook **checkout.session.completed** and backend will match the session id once on the database with one received from the webhook, the backend will update the status of the payment in the database) Than the person will be redirected to the success page then the main page.
